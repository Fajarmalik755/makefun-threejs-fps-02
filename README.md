Make the best three.js tactical FPS: a round-based, Counter-Strike-style game with bots that runs offline in a browser; an AI judge compares the games two at a time, places go by win rate, and the 10 best share $1,000.

STRIKE PROTOCOL is a complete round-based tactical FPS: 5v5 bots, bomb sites A/B, a buy menu with weapons and armor, money earned per round, first to 3 rounds. It runs fully offline from static files — three.js 0.187.0 vendored under `game/vendor/three/`, no network requests, no build step.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Click DEPLOY to play as Attacker (WASD to move, mouse to look, click to fire, R to reload, B for the buy menu), or pick Bot Demo to watch the 10 bots play a round by themselves.
